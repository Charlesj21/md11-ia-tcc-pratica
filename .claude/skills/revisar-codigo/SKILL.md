# Skill: Revisar Código C#

## Objetivo
Esta skill orienta o assistente de IA a efetuar revisões de código estruturadas em ficheiros C# do projeto `GerenciadorDeTarefas`, focando-se em boas práticas, legibilidade e padrões de desenvolvimento.

## Instruções de Execução
Quando esta skill for acionada, siga rigorosamente estes passos:
1. Analise o código C# presente no ficheiro ou na seleção atual.
2. Verifique se as convenções de nomenclatura da Microsoft estão a ser aplicadas (PascalCase para classes e métodos, camelCase para variáveis).
3. Aponte eventuais melhorias na estrutura de controlo ou lógica de negócio.
4. Apresente as sugestões de melhoria de forma clara, organizada por tópicos e com exemplos de código corrigido.
